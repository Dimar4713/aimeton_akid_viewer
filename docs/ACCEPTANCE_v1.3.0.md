# Эксплуатационная приёмка AIMETON AKID Viewer v1.3.0

Дата: 2026-08-10  
Статус: **пройдено**

## Основание

После выпуска `v1.3.0` обе опубликованные Windows-сборки были скачаны и проверены в реальной эксплуатации.

Проверены:

- `AIMETON_AKID_Viewer_1.3.0_Windows_x64.exe` — основная Windows x64 сборка;
- `AIMETON_AKID_Viewer_1.3.0_Windows7_x64.exe` — Windows 7 x64 Legacy сборка.

## Подтверждённый функционал

По результатам ручного тестирования подтверждено, что в обеих версиях работает затребованный дополнительный функционал:

1. Назначение **нескольких исполнителей на одну задачу**.
2. **Группировка по назначенным исполнителям**.
3. Корректная работа отдельной **Windows 7 x64 Legacy** сборки.

Также в составе текущей линии сохраняются ранее принятые функции:

- загрузка XLSX/XLS и CSV;
- персональные выдачи;
- экспорт;
- конфигурации;
- автозагрузка последних файлов;
- встроенная отрендеренная справка по кнопке `[?]`;
- PDF-руководство в Release.

## Технические свидетельства

До выпуска CI подтвердил:

- успешную современную Windows x64 сборку;
- успешную Windows 7 x64 сборку на Electron `22.3.27`;
- smoke-test модели множественных назначений;
- обратную совместимость старых одиночных назначений;
- наличие modern EXE, Windows 7 EXE, BAT и PDF в Release.

Ручная эксплуатационная проверка закрыла оставшийся gap между CI и реальной Windows-средой.

## Решение

`v1.3.0` принимается как **эксплуатационно проверенный релиз** для пилотного использования.

Windows 7 артефакт остаётся классифицирован как **Legacy**, поскольку Electron 22 и Windows 7 находятся вне актуальной upstream-поддержки. Это ограничение относится к жизненному циклу платформы, а не к результату приёмки текущего релиза.
