# Руководство пользователя — Мониторинг работ АКИД/АКИП

Версия руководства: 1.0  
Актуально для: `AIMETON AKID Viewer v1.2.1` и новее

## 1. Назначение программы

Viewer предназначен для удобной работы с планами и задачами, хранящимися в таблицах Excel, без изменения исходной корпоративной системы.

Программа позволяет:

- загружать план работ из XLSX/XLS;
- загружать справочник исполнителей из CSV;
- быстро искать и фильтровать работы;
- группировать строки по выбранному признаку;
- скрывать и показывать столбцы;
- сортировать таблицу;
- назначать исполнителей на работы;
- формировать персональные выдачи исполнителям;
- сохранять рабочие выборки и назначения;
- экспортировать результаты в XLSX, Markdown и формат, удобный для Obsidian;
- сохранять и переносить конфигурацию работы через JSON-файл;
- автоматически восстанавливать последние использованные рабочие файлы при повторном запуске.

Программа работает локально на компьютере пользователя и не требует подключения к Интернету.

## 3. Первый запуск в Windows

### 3.1. Если Windows показывает предупреждение о файле из Интернета

Положите EXE и `UNBLOCK_AKID_VIEWER.bat` в одну папку.

Запустите:

`UNBLOCK_AKID_VIEWER.bat`

BAT-файл найдёт Viewer в своей папке и штатной командой Windows PowerShell снимет Internet-zone marker с EXE.

После сообщения об успешном завершении закройте окно BAT и запустите Viewer обычным двойным щелчком.

> BAT снимает только метку «файл загружен из Интернета». Он не отключает Windows SmartScreen и не меняет системные политики безопасности.

### 3.2. Ручной способ

Если BAT не разрешён политиками организации:

1. Нажмите правой кнопкой мыши на EXE.
2. Откройте **Свойства**.
3. Если внизу окна есть пункт **Разблокировать**, включите его.
4. Нажмите **Применить** → **ОК**.
5. Запустите программу снова.

Если корпоративные политики полностью запрещают запуск неподписанных приложений, потребуется разрешение ИТ/ИБ организации.

## 4. Рекомендуемая рабочая папка

Для удобной эксплуатации можно создать отдельную папку, например:

```text
AKID_Viewer\
  AIMETON_AKID_Viewer_1.2.1_Windows_x64.exe
  UNBLOCK_AKID_VIEWER.bat
  employees.csv
```

Файл плана работ XLSX может находиться в любой доступной пользователю папке.

Если рядом с EXE находится файл с точным именем `employees.csv`, программа пытается загрузить его автоматически при старте.

---

## 5. Стартовый экран

При первом запуске Viewer показывает два блока:

- **Файл с работами** — загрузка XLSX/XLS;
- **Файл исполнителей** — загрузка CSV/TXT.

Для начала основной работы достаточно загрузить файл плана.

CSV исполнителей нужен для назначения людей и формирования персональных выдач.

---

## 6. Загрузка плана работ

Нажмите **Файл с работами** на стартовом экране или кнопку **Работы** в верхней панели.

Поддерживаются:

- `.xlsx`;
- `.xls`.

После загрузки Viewer читает таблицу локально и отображает строки в рабочем интерфейсе.

Исходный Excel-файл программа не изменяет автоматически.

### Автовосстановление

После ручного выбора XLSX Viewer запоминает его путь.

При следующем запуске программа пытается открыть последний успешно использованный файл автоматически.

Если файл был удалён, переименован, перемещён или стал недоступен, программа не должна аварийно завершаться — выберите актуальный XLSX вручную.

---

## 7. Загрузка исполнителей

Нажмите **Файл исполнителей** на стартовом экране или кнопку **Исполнители** в верхней панели.

Ожидается CSV со значениями, разделёнными `;`.

Типовой набор полей может содержать:

- ФИО;
- сектор/подразделение;
- должность;
- иные сведения, необходимые для работы.

### Приоритет автоматической загрузки

При запуске EXE используется следующий порядок:

1. `employees.csv` рядом с EXE;
2. если такого файла нет — последний ранее выбранный CSV исполнителей;
3. если ни один файл недоступен — пользователь выбирает CSV вручную.

Рабочие CSV не копируются в репозиторий и не отправляются в Интернет.

---

## 8. Основной рабочий экран

После загрузки плана открывается таблица работ.

В верхней части доступны:

- переключатель светлой/тёмной темы;
- **Работы** — заменить или повторно загрузить XLSX;
- **Исполнители** — загрузить CSV;
- **Выдачи** — открыть сформированные персональные выдачи;
- **Сохранить** — сохранить текущую рабочую выборку;
- **Загрузить конфиг** — импортировать JSON-конфигурацию;
- **Сохранить конфиг в файл** — экспортировать конфигурацию;
- **Экспорт** — экспортировать текущую выборку;
- кнопка сброса состояния.

---

## 9. Фильтры и поиск

Раздел **ФИЛЬТРЫ И ПОИСК** позволяет сузить набор отображаемых работ.

Доступные фильтры формируются на основе структуры загруженного файла.

Можно одновременно использовать несколько условий.

Справа над таблицей расположен общий поиск. Он применяется к отображаемым данным и позволяет быстро найти строку по фрагменту текста.

Практический сценарий:

1. ограничить выборку нужным подразделением или состоянием;
2. выполнить текстовый поиск;
3. при необходимости сгруппировать результат;
4. экспортировать только получившуюся выборку.

---

## 10. Группировка

В поле **Группировка** выберите нужный столбец.

Viewer объединит строки в визуальные группы по значениям выбранного поля.

Для возврата к обычной таблице выберите **Нет**.

Группировка влияет на отображение и может использоваться при формировании удобного представления перед экспортом.

---

## 11. Сортировка

Нажмите на заголовок столбца таблицы для сортировки.

Повторные нажатия меняют направление сортировки.

Активный отсортированный столбец визуально выделяется.

---

## 12. Настройка столбцов

Нажмите **Столбцы**.

В панели можно включать и отключать отображение отдельных колонок.

Это удобно, если исходная таблица очень широкая и для текущей задачи нужны только несколько полей.

Ширину столбцов можно подстраивать в рабочей таблице.

---

## 13. Назначение исполнителя

Для строк, поддерживающих назначение, используется действие назначения исполнителя.

После открытия окна **Назначить исполнителя** доступны:

- поиск человека по справочнику;
- фильтрация по сектору/подразделению;
- выбор конкретного исполнителя.

Назначения сохраняются в локальном состоянии Viewer и могут входить в сохраняемые выборки/конфигурации.

Назначение в Viewer само по себе не изменяет исходную корпоративную систему и не отправляет данные во внешние сервисы.

---

## 14. Персональные выдачи

Кнопка **Выдачи** открывает список сформированных выдач по исполнителям.

В выдаче можно получить набор назначенных конкретному человеку работ.

Доступны действия:

- экспорт в XLSX;
- экспорт в Markdown;
- экспорт в представление для Obsidian;
- копирование текста в буфер обмена.

Это позволяет быстро превратить общий план в персональный рабочий список.

---

## 15. Сохранённые выборки

Кнопка **Сохранить** сохраняет текущее рабочее состояние выборки.

В сохранение могут входить:

- активные фильтры;
- текст поиска;
- группировка;
- назначения исполнителей;
- другие параметры текущего представления.

Сохранённые выборки отображаются в нижней части рабочего интерфейса.

Используйте понятные названия, например:

- `Сектор 12 — август`;
- `Просроченные работы`;
- `Выдача на совещание`;
- `Работы Иванова`.

---

## 16. Конфигурация JSON

### Сохранить

Нажмите **Сохранить конфиг в файл**.

Viewer сформирует JSON-файл с переносимой конфигурацией текущей работы.

### Загрузить

Нажмите **Загрузить конфиг** и выберите ранее сохранённый JSON.

Это удобно для:

- резервного копирования настроек;
- переноса рабочего состояния;
- подготовки стандартных представлений для повторяющихся задач.

Перед передачей JSON другому человеку следует учитывать, что конфигурация может содержать рабочие назначения или другие внутренние сведения.

---

## 17. Экспорт текущей выборки

Нажмите **Экспорт**.

Поддерживаются:

- **XLSX** — для дальнейшей работы в Excel;
- **MD** — Markdown;
- **Obsidian** — текстовое представление для работы в Obsidian;
- **Копировать** — копирование подготовленного текста в буфер обмена.

Дополнительные параметры окна экспорта позволяют, в зависимости от версии Viewer:

- группировать экспортируемые строки;
- экспортировать только назначенные работы.

Перед экспортом рекомендуется сначала настроить фильтры, поиск, группировку и видимые данные.

---

## 18. Повторный запуск

При обычном повторном запуске Viewer пытается максимально быстро восстановить рабочее окружение:

- найти `employees.csv` рядом с EXE;
- либо открыть последний CSV;
- открыть последний XLSX;
- восстановить локально сохранённые настройки приложения.

Поэтому для постоянной эксплуатации удобно не перемещать рабочие файлы без необходимости.

Если структура папок изменилась, просто выберите нужные файлы снова — новые пути будут запомнены.

---

## 19. Где хранятся данные

Viewer является локальным desktop-приложением.

Он не требует backend и не отправляет рабочие таблицы в Интернет.

В пользовательском каталоге приложения могут локально сохраняться:

- пути последних файлов;
- настройки интерфейса;
- фильтры;
- назначения;
- сохранённые представления.

Исходные XLSX/CSV остаются там, где их разместил пользователь.

Для файлов с персональными и внутренними сведениями применяйте действующие правила информационной безопасности вашей организации.

## 20. Сброс состояния

Кнопка со значком круговой стрелки в верхней панели предназначена для сброса текущего рабочего состояния.

Перед сбросом важных настроек рекомендуется экспортировать конфигурацию JSON, если она понадобится позже.

## 21. Типовые проблемы

### Windows пишет «Неизвестный издатель»

Текущая pilot-сборка не имеет публичной Authenticode-подписи.

Это не означает, что программа требует Интернет или установщик.

Используйте `UNBLOCK_AKID_VIEWER.bat` для снятия Internet-zone marker. Если запуск неподписанных приложений запрещён корпоративной политикой, обратитесь в ИТ/ИБ.

### BAT не нашёл EXE

Убедитесь, что BAT и EXE находятся в одной папке и имя EXE имеет формат:

`AIMETON_AKID_Viewer_*_Windows_x64.exe`

### Не загрузился `employees.csv`

Проверьте:

- точное имя файла: `employees.csv`;
- файл находится рядом с EXE;
- у пользователя есть права на чтение файла;
- CSV имеет ожидаемую структуру и разделитель `;`.

При необходимости загрузите файл кнопкой **Исполнители**.

### Последний XLSX не открылся автоматически

Скорее всего, файл был перемещён, переименован, удалён или стал недоступен.

Нажмите **Работы** и укажите актуальный файл вручную.

### Таблица отображается необычно

Проверьте структуру исходного XLSX. Если в корпоративной системе изменились названия/порядок столбцов или формат листа, Viewer может потребовать адаптацию.

### Нужного человека нет в назначениях

Перезагрузите актуальный CSV кнопкой **Исполнители** и проверьте данные сотрудника в исходном файле.

## 22. Рекомендуемый рабочий процесс

Для ежедневной эксплуатации:

1. один раз поместить EXE, BAT и `employees.csv` в постоянную рабочую папку;
2. один раз снять Internet-zone blocking;
3. открыть актуальный XLSX плана;
4. настроить нужные столбцы;
5. применить фильтры и поиск;
6. назначить исполнителей;
7. сформировать персональные выдачи;
8. при необходимости экспортировать XLSX/MD;
9. сохранить важную конфигурацию JSON;
10. при следующем запуске использовать автоматическое восстановление файлов.

---

## 23. Ограничения текущей версии

Viewer является вспомогательным рабочим инструментом и не заменяет исходную корпоративную информационную систему.

В частности:

- изменения в Viewer не синхронизируются автоматически с корпоративной системой;
- Viewer не является многопользовательским сервером;
- локальные назначения одного пользователя не являются общей централизованной базой;
- структура импортируемого XLSX/CSV должна оставаться совместимой с текущим парсером;
- публичная подпись издателя для Windows пока отсутствует.

## 25. Краткая памятка

**Первый запуск:**

`EXE + BAT в одной папке → запустить BAT → запустить EXE`

**Каждый день:**

`запустить EXE → последний XLSX/CSV восстановятся автоматически, если доступны`

**Сменить план:**

`Работы → выбрать новый XLSX`

**Сменить список сотрудников:**

`Исполнители → выбрать новый CSV`

**Сделать персональный список:**

`назначить исполнителей → Выдачи → выбрать человека → XLSX/MD/Obsidian`

**Сохранить рабочее состояние:**

`Сохранить конфиг в файл`
