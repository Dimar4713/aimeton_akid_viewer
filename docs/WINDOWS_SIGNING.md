# Windows trust and code signing

## Почему Windows показывает «Неизвестный издатель»

Portable EXE, собранный без Authenticode-подписи, не содержит проверяемой идентичности издателя. Microsoft Defender SmartScreen поэтому может показывать предупреждение при первом запуске скачанного файла.

Это не ошибка Viewer и не связано с его офлайн-режимом. Для нормальной корпоративной эксплуатации нужен доверенный путь подписи или централизованного доверия.

## Рекомендуемая модель AIMETON

### Публичные и межкорпоративные поставки

Подписывать каждый release сертификатом code signing, выданным доверенным УЦ, либо облачным сервисом доверенной подписи, совместимым с Authenticode.

GitHub Actions уже подготовлен к такому режиму. Секреты репозитория:

- `WIN_CSC_LINK` — PFX/P12, путь/URL либо поддерживаемое electron-builder base64-представление сертификата;
- `WIN_CSC_KEY_PASSWORD` — пароль закрытого ключа.

Сертификат и пароль нельзя коммитить в репозиторий.

При наличии `WIN_CSC_LINK` electron-builder подписывает Windows EXE, а CI дополнительно выполняет `Get-AuthenticodeSignature` и требует статус `Valid`.

### Пилот внутри одной крупной корпорации

Если приложение распространяется только внутри одной организации, возможен корпоративный контур доверия:

1. служба ИБ/ИТ организации принимает приложение;
2. либо организация подписывает поставляемый EXE собственным корпоративным сертификатом;
3. либо доверяет отдельному сертификату издателя AIMETON централизованно через корпоративные политики/PKI;
4. после этого распространение выполняется через утверждённый корпоративный канал.

Такой вариант особенно уместен для пилота, где внешний публичный SmartScreen-рейтинг не является целью, а главным требованием является доверие рабочих станций конкретной организации.

## Release gate

Перед внешней передачей подписанной версии проверить:

- единственный portable Windows x64 EXE;
- Authenticode signature status = `Valid`;
- имя издателя соответствует владельцу сертификата;
- приложение полностью работает без Интернета;
- в release не попадают рабочие XLSX/CSV и персональные/внутренние данные;
- SHA-256 опубликован вместе с release evidence.
