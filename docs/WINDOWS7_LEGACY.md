# Windows 7 Legacy build

## Назначение

Для рабочих мест на Windows 7 выпускается отдельная portable-сборка:

`AIMETON_AKID_Viewer_<version>_Windows7_x64.exe`

Она не заменяет основную сборку для Windows 10/11 и предназначена только для тех рабочих мест, где обновление ОС пока невозможно.

## Почему отдельная сборка

Основная версия Viewer использует современный Electron. Начиная с Electron 23 официальная поддержка Windows 7/8/8.1 удалена.

Поэтому Windows 7 build фиксируется на Electron `22.3.27` — последней основной линии Electron, совместимой с Windows 7.

## Ограничения и риск

Electron 22 находится вне upstream-поддержки и больше не получает актуальные исправления Chromium/Electron. Поэтому:

- Windows 7 build считается **legacy**, а не основной production-платформой;
- его следует использовать только в контролируемом корпоративном контуре;
- приложение остаётся локальным/offline и не должно использоваться как браузер общего назначения;
- внешние web-ссылки Viewer не открывает внутри своего Chromium, а передаёт операционной системе;
- по возможности рабочее место следует переводить на поддерживаемую Windows и использовать основной EXE.

## Совместимость файлов и функций

Windows 7 и современная Windows-сборка используют одну и ту же прикладную модель Viewer:

- XLSX/XLS планы;
- CSV исполнителей;
- несколько исполнителей на одной задаче;
- группировка по назначенным исполнителям;
- персональные выдачи;
- экспорт XLSX/Markdown/Obsidian;
- JSON-конфигурации;
- встроенное руководство `[?]`;
- автозагрузка последних файлов.

Для старого Electron используется отдельный preload-мост без современных Electron API, отсутствующих в ветке 22.

## Приёмка

CI проверяет, что legacy EXE фактически собирается с Electron `22.3.27` и что в Release присутствуют отдельные modern и Windows 7 x64 артефакты.

GitHub Actions выполняет сборочную проверку, но не эмулирует реальную Windows 7. Поэтому перед широким распространением legacy EXE требуется smoke-test на реальном корпоративном ПК с Windows 7: запуск, открытие XLSX/CSV, назначения, группировка, выдача, экспорт и встроенная справка.
