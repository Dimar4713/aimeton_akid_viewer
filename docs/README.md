# Документация AIMETON AKID Viewer

> Статус: руководство пользователя одобрено владельцем проекта 2026-08-09 и принято как базовая пользовательская документация для `v1.2.1`.

## Для пользователей

- [Руководство пользователя](USER_GUIDE_RU.md) — установка не требуется, первый запуск, Windows-разблокировка, XLSX/CSV, фильтры, группировка, назначения, выдачи, экспорт, конфигурации и типовые проблемы.
- Встроенная справка открывается кнопкой `[?]` в правом верхнем углу и рендерит это же руководство в прокручиваемом окне.
- Начиная с линии `v1.3.x`, одна задача может иметь нескольких назначенных исполнителей.
- В поле **Группировка** доступен отдельный вариант **Назначенные исполнители**. Если на задаче несколько людей, задача отображается в группе каждого из них; неназначенные работы попадают в группу **Без исполнителя**.

## Для сопровождения и сборки

## Быстрый старт

1. Скачать из актуального Release нужный portable EXE и `UNBLOCK_AKID_VIEWER.bat`.
2. Для Windows 10/11 использовать обычный `..._Windows_x64.exe`.
3. Для Windows 7 x64 использовать только `..._Windows7_x64.exe` с пометкой Legacy.
4. Положить EXE и BAT в одну папку.
5. При необходимости запустить BAT один раз для снятия Internet-zone marker.
6. Запустить EXE.
7. При необходимости открыть встроенную справку кнопкой `[?]`.
8. Загрузить XLSX с работами.
9. Положить `employees.csv` рядом с EXE либо выбрать CSV исполнителей вручную.

Подробности: [Руководство пользователя](USER_GUIDE_RU.md).
