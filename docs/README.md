## Быстрый старт

1. Скачать из актуального Release portable EXE и `UNBLOCK_AKID_VIEWER.bat`.
2. Положить оба файла в одну папку.
3. При необходимости запустить BAT один раз для снятия Internet-zone marker.
4. Запустить EXE.
5. При необходимости открыть встроенную справку кнопкой `[?]`.
6. Загрузить XLSX с работами.
7. Положить `employees.csv` рядом с EXE либо выбрать CSV исполнителей вручную.

Подробности: [Руководство пользователя](USER_GUIDE_RU.md).
