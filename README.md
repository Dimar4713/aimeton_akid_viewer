## Для конечного пользователя: один EXE

При публикации GitHub Release автоматически собирается один portable-файл для Windows x64:

`AIMETON_AKID_Viewer_<version>_Windows_x64.exe`

Он не требует установки, Node.js или доступа в Интернет.

В Release также прикладывается `UNBLOCK_AKID_VIEWER.bat`, который можно использовать для снятия Windows Internet-zone marker с загруженного EXE без отключения SmartScreen целиком.

Release tag должен иметь вид `v1.2.3` или `1.2.3`. Версия автоматически переносится в имя EXE.

Сборка выполняется workflow `.github/workflows/build-windows-exe.yml` на Windows runner и после успешной проверки автоматически прикрепляется к опубликованному GitHub Release.

## Автоматическая загрузка рабочих файлов

Windows EXE упрощает повторный запуск:

1. при старте сначала ищет файл `employees.csv` рядом с EXE и, если находит, автоматически загружает его;
2. если `employees.csv` рядом с EXE нет, пытается открыть последний ранее выбранный CSV исполнителей;
3. запоминает путь последнего выбранного XLSX с работами и при следующем запуске автоматически пытается загрузить его;
4. запоминает путь последнего выбранного CSV исполнителей;
5. если сохранённый файл был перемещён или удалён, Viewer не падает — пользователь может выбрать новый файл вручную.

Пути последних файлов хранятся локально в пользовательском каталоге приложения, а сами рабочие XLSX/CSV никуда не копируются и не отправляются.

## Главное свойство: работа без Интернета

Runtime приложения полностью локальный. EXE содержит Viewer и его локальные зависимости; backend не требуется.

Исходная браузерная версия также остаётся автономной. После клонирования или скачивания репозитория она не обращается к внешним CDN.

Все runtime-зависимости хранятся локально в `lib/`:

- Tailwind browser runtime;
- SheetJS/XLSX;
- Font Awesome и необходимые webfonts.

Для браузерного запуска достаточно открыть `index.html` в современном браузере.

Пользовательские настройки, фильтры и назначения сохраняются локально.

## Разработка и упаковка

Electron используется только как оболочка для локального Viewer. В renderer отключена Node.js integration, включены `contextIsolation`, `sandbox` и `webSecurity`. Доступ к локальным файлам для автозагрузки выполняется через узкий preload/IPC-мост.

Локальная упаковка Windows:

```bash
npm install
npm run build:win
```

Результат появляется в `dist/` как один portable `.exe`.

## Данные

Рабочие XLSX/CSV из исходного архива намеренно не публикуются в этом публичном репозитории: они могут содержать персональные и внутренние рабочие сведения. Viewer работает с файлами, которые пользователь выбирает локально на своём компьютере.
