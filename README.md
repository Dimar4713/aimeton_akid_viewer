# AIMETON AKID Viewer

Автономный офлайн-viewer для мониторинга работ АКИД/АКИП.

## Главное свойство: работа без Интернета

После клонирования или скачивания репозитория приложение не обращается к внешним CDN и не требует backend.

Все runtime-зависимости хранятся локально в `lib/`:

- Tailwind browser runtime;
- SheetJS/XLSX;
- Font Awesome и необходимые webfonts.

Для запуска достаточно открыть `index.html` в современном браузере. Затем через интерфейс локально загрузить XLSX с работами и CSV с исполнителями.

Пользовательские настройки, фильтры и назначения сохраняются в браузере (`localStorage`).

## Данные

Рабочие XLSX/CSV из исходного архива намеренно не публикуются в этом публичном репозитории: они могут содержать персональные и внутренние рабочие сведения. Viewer работает с файлами, которые пользователь выбирает локально на своём компьютере.
