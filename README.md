# AIMETON AKID Viewer

Автономный офлайн-viewer для мониторинга работ АКИД/АКИП.

## Запуск

Откройте `index.html` в современном браузере и загрузите XLSX с работами и CSV с исполнителями через интерфейс.

Приложение хранит пользовательские настройки и назначения локально в браузере (`localStorage`) и не требует backend.
