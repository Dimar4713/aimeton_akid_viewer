# Корпоративный UX Viewer

> Локальный рабочий слой поверх тяжёлой корпоративной системы планирования и контроля.

**Готовый desktop-продукт для Windows, который превращает XLSX/CSV-выгрузки в удобный рабочий интерфейс — без вмешательства в ядро корпоративной системы.**

[Скачать актуальный релиз](https://github.com/Dimar4713/aimeton_akid_viewer/releases/latest) · [Руководство пользователя](docs/USER_GUIDE_RU.md)

---

## Какая проблема решается

В крупных корпоративных системах автоматизированного планирования, контроля и документооборота функциональность часто богаче, чем ежедневный пользовательский интерфейс.

Типичные последствия:

- трудно быстро найти нужные работы;
- широкие таблицы перегружены служебными полями;
- фильтрация и группировка неудобны для ежедневной работы;
- сложно оперативно сформировать персональный список задач;
- приходится вручную переносить сведения в Excel, заметки или дополнительные таблицы;
- замена основной корпоративной системы невозможна или экономически нецелесообразна.

Корпоративный UX Viewer решает эту задачу **как тонкий внешний слой удобства**: основная система остаётся источником данных и учёта, а пользователь получает более удобное рабочее представление.

---

## Что делает Viewer

- открывает планы работ из XLSX/XLS;
- загружает локальный справочник исполнителей из CSV;
- выполняет быстрый полнотекстовый поиск;
- фильтрует и группирует работы;
- позволяет скрывать ненужные столбцы и менять представление таблицы;
- назначает исполнителей локально;
- формирует персональные выдачи задач;
- экспортирует выборки в XLSX и Markdown;
- формирует представление для Obsidian;
- сохраняет рабочие конфигурации в JSON;
- запоминает последние использованные файлы;
- содержит встроенное руководство пользователя по кнопке `[?]`.

---

## Почему это удобно для корпоративной среды

### Не требует интеграционного проекта

Viewer работает с разрешёнными файловыми выгрузками. Для первого полезного результата не требуется менять ядро корпоративной системы, API или её бизнес-логику.

### Работает офлайн

Основной runtime локальный. Рабочие XLSX/CSV не отправляются во внешние сервисы и остаются на компьютере пользователя.

### Portable Windows-приложение

Приложение поставляется одним EXE и не требует установки Node.js, backend или отдельного сервера.

### Минимальный порог внедрения

Можно начать с одного подразделения или группы пользователей, измерить эффект и только после этого принимать решение о дальнейшем развитии.

## Типовой рабочий сценарий

1. Пользователь получает актуальную XLSX-выгрузку из корпоративной системы.
2. Viewer автоматически или вручную открывает её.
3. Пользователь оставляет только необходимые столбцы и применяет фильтры.
4. Находит нужные работы поиском.
5. При необходимости назначает исполнителей.
6. Формирует персональные выдачи.
7. Экспортирует рабочий набор в XLSX/Markdown или сохраняет конфигурацию.

Корпоративная система при этом продолжает выполнять свою основную функцию — хранение, учёт и контроль официальных данных.

## Безопасность и данные

Viewer не публикует и не содержит реальные рабочие XLSX/CSV. Пользовательские файлы выбираются локально.

Приложение:

- не требует backend;
- не отправляет рабочие таблицы в Интернет;
- не изменяет исходный корпоративный файл автоматически;
- не синхронизирует локальные назначения обратно в корпоративную систему без отдельной интеграции;
- рассчитано на соблюдение внутренних правил ИБ организации при работе с корпоративными данными.

## Для каких задач подходит этот подход

Паттерн можно адаптировать к другим корпоративным системам, если у пользователей есть доступ к разрешённым выгрузкам или API, а основная боль находится именно в рабочем интерфейсе.

Примеры:

- системы планирования и контроля;
- СЭД и документооборот;
- ERP/учётные системы;
- реестры и производственные таблицы;
- внутренние системы поручений;
- технические журналы и контрольные перечни.
